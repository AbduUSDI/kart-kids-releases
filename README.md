# Kart Kids — mises à jour

Ce dépôt ne contient que les **binaires** de Kart Kids (jeu de kart 3D pour les tout-petits), publiés par `npm run electron:publish` depuis le dépôt source privé `AbduUSDI/kart-kids`.

- Les jeux Windows installés lisent `latest.yml` de la dernière release pour se mettre à jour tout seuls (electron-updater).
- `Kart-Kids-<version>-x64.exe` : installeur Windows en français.

Le code source, les ressources et les décisions produit restent dans le dépôt privé.
